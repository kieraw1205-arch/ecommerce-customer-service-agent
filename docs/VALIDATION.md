本轮出现与修复：

1. 新测试先确认自动 dotenv 加载仍发生，离线示例尚不存在（2 个预期失败）。随后移除隐式加载，添加明确标注的边界替身示例。
2. 首次完整回归发现从仓库根目录运行时恢复测试子进程无法导入 my_agent。测试入口显式设置仅公开 backend/evaluation 的 PYTHONPATH，保留真实跨进程恢复断言。
3. 离线意图 fixture 参数名与实际 user_message 关键字不一致，触发原异常处理而非订单结果；修正 fixture 签名，未修改 Graph 或评分标签。
4. 模型/工具/API Trace 均来自实际离线执行；无 provider usage 时 Token 保持 null/reported=false，示例真实模型调用 0、真实业务写入 0。

原始 red/首轮失败/green 日志、上下文与构建失败记录保存在私有验收包；公开示例输出见 examples/offline-output.json，包含虚构事实和安全 Trace，不含令牌。
